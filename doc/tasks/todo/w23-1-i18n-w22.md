# Phase 1 — i18n localize W22 (đóng nợ)

## Nợ
W21.6 + W22 thêm ~23 key UI chỉ **en + vi**; 20 ngôn ngữ fallback English. Hiện **tạm loại
khỏi ratio** trong `test/app_translations_test.dart` (`universalKeys`) để giữ test xanh.

## Key cần dịch (đã liệt kê trong universalKeys)
- Leaderboard: `leaderboard_title`, `lb_tab_campaign`, `lb_tab_daily`, `lb_level`, `lb_player`, `lb_daily_note`
- Game Feel: `reduce_motion`
- Onboarding: `tour_t0..t3`, `tour_m0..m3`, `tour_skip`, `tour_next`, `tour_done`
- Chest: `chest_reward_title`, `chest_got_coins` (có `@n`), `chest_got_hammer`, `chest_got_moves`, `chest_ok`

## Cách làm (theo [[i18n-extra-merge]] + [[i18n-coverage-gap]])
1. Thêm `static const Map<String, Map<String,String>> _w22ByLang` trong `app_translations.dart`:
   mỗi ngôn ngữ (20 mã: es/fr/de/pt/ru/zh/ja/ko/it/id/th/hi/ar/tr/nl/pl/fil/ms/uk/bn) → map key→bản dịch.
2. Merge trong getter `keys` SAU các `_wXXByLang` khác: `...?_w22ByLang[e.key]`.
3. **Gỡ** các key W22 khỏi `universalKeys` trong test.
4. Giữ placeholder `@n` trong `chest_got_coins` cho mọi ngôn ngữ.
5. RTL (ar): kiểm chuỗi không vỡ; số trong `@n` giữ đúng.

## Acceptance
- [ ] 22/22 ngôn ngữ: ratio khác-English ≥ 80% (test `app_translations_test` pass mà KHÔNG cần exclusion W22).
- [ ] Không key nào lộ raw (`tour_t0`…) ở bất kỳ locale.
- [ ] `chest_got_coins` thay `@n` đúng mọi ngôn ngữ.
- [ ] `flutter analyze` 0; full suite pass.

- Đây là task DỊCH thuần (data) — rủi ro thấp, chỉ cần đúng convention + đủ 20 ngôn ngữ.
