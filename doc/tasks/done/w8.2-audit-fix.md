# Wave 8.2 — Audit code & fix lỗ hổng đã xác minh

> Tự audit toàn dự án (2 agent đọc sâu logic/game + presentation/data) → sửa
> các lỗ hổng đã đọc-xác-minh trong code (không bịa).

## Đã fix

### 1. `resetProgress()` không sạch + exploit nhận lại thưởng (Critical)
- **Gốc**: chỉ xoá key đĩa của Battle Pass / Season / Achievement / Temple,
  nhưng các controller `permanent:true` vẫn giữ `claimed`/`xp`/`points`/`builtTier`
  trong RAM. Restart → `onInit` đọc đĩa trống → người chơi **nhận lại** toàn bộ
  thưởng (lặp xu/shard). Ngoài ra bỏ sót hẳn key `coins`, `daily*`, `wheelLastSpin`,
  `lives*`, 9 `booster*`, `tutorialSeen`, `viewMode` → "reset" mà xu/booster/mạng còn nguyên.
- **Fix**: thêm `resetState()` cho 4 controller meta (clear in-memory + reload từ
  đĩa đã trống). `resetProgress` xoá ĐỦ key rồi gọi `_load()` để đưa về mặc định
  cài đầu (50 xu, booster default, đầy mạng), rồi gọi `*.resetState()`.

### 2. Boss "điểm yếu màu" dở dang (feature chưa wire)
- **Gốc**: `bossWeakColor` được tính + đổi theo phase nhưng KHÔNG ảnh hưởng sát
  thương (×2 chỉ theo combo) và KHÔNG hiển thị HUD → cơ chế "đánh đúng màu yếu"
  chỉ là state chết.
- **Fix**: `registerClear` bật `_weakHitPending` khi clear trúng màu yếu →
  `_bossDamage` ×2 (cộng dồn với ×2 combo lớn = tối đa ×4). HUD boss thêm chỉ báo
  "ĐIỂM YẾU ● ×2" (key i18n `boss_weak` đã có sẵn en/vi, trước đây không dùng).
